Каталог для рабочей книги 2026_01_Ord_Quantity.xlsx.

Итоговая цель (final goal): в книге заполнены листы «СВОД_операций» и «Количество поручений»
(матрица Ord_Quantity по счетам депо и типам поручений).

-------------------------------------------------------------------------------
Предварительные условия
-------------------------------------------------------------------------------
- Входные файлы отчётов разложить по каталогам под 2026_01 (см. memory/GBP_files_structure.md
  и memory/Svod_sheet_spec.md): например GPB/I, GPB/D, GPB/REP, при необходимости RSD, REGION, VTBSD.
- В книге Excel должны быть справочники (reference sheets) «Счета депо» и «Коды» — без них
  fill_svod / fill_dks / fill_reps не смогут корректно подставить депозитарий (depository),
  владельца (owner) и типы операций. Обычно их копируют из эталонной книги прошлого периода
  или заполняют вручную. Для локального теста у fill_svod есть флаги --seed-demo-data
  и --ensure-reference-sheets (см. scripts/fill_svod_from_i_msg.py --help).

-------------------------------------------------------------------------------
Рекомендуемый порядок шагов (предварительные листы → СВОД → Ord_Quantity)
-------------------------------------------------------------------------------
1) Создать шаблон с листами «Количество поручений» и «СВОД_операций» (только шапки):
     python scripts/init_ord_quantity_workbook.py --out 2026_01/2026_01_Ord_Quantity.xlsx

2) Добавить в эту книгу листы «Счета депо» и «Коды» (если их ещё нет).

3) Лист Dks (документы КД из отчётов D*.MSG, формат DOC_INSTRUCT):
     python scripts/fill_dks_from_d_msg.py --workbook 2026_01/2026_01_Ord_Quantity.xlsx
   При отсутствии файла книги: добавить --create-workbook (создаётся книга с Dks и «Счета депо» —
   тогда позже всё равно понадобятся «СВОД_операций», «Количество поручений» и «Коды»).

4) Лист REPs (отчёты об исполнении REP_*.xls / REP_*.xlsx для сценариев T/Y и сверки):
     python scripts/fill_reps_from_rep_xls.py --workbook 2026_01/2026_01_Ord_Quantity.xlsx
   При отсутствии файла: --create-workbook.

5) Лист «СВОД_операций» (I*.MSG, при необходимости R-01, REGION, ВТБ СД, D*.MSG и т.д.):
     python scripts/fill_svod_from_i_msg.py --workbook 2026_01/2026_01_Ord_Quantity.xlsx
   При отсутствии файла: --create-workbook (пустая книга только со СВОД) или используйте шаг 1.
   Полный список каталогов и флагов: python scripts/fill_svod_from_i_msg.py --help

6) Лист «Количество поручений» — агрегация (aggregation) из «СВОД_операций» за месяц:
     python scripts/fill_ord_quantity_from_svod.py --workbook 2026_01/2026_01_Ord_Quantity.xlsx --year 2026 --month 1

-------------------------------------------------------------------------------
Проверка массива данных скриптами сверки (reconciliation)
-------------------------------------------------------------------------------
Нужна отдельная эталонная книга (sample workbook) — например вручную сверенный xlsx за тот же
период, копия прошлого проверенного отчёта или выгрузка, признанная эталоном. Тестируемая книга
(test) — обычно 2026_01/2026_01_Ord_Quantity.xlsx после fill_*.

Когда запускать:
- compare_svod_sheet.py — после шага 5 (лист «СВОД_операций» уже пересобран). Имеет смысл
  до шага 6: сначала убедиться, что СВОД совпадает с образцом, затем строить «Количество поручений».
- compare_reps_sheet.py — после шагов 4 и 5: сверяет лист REPs с эталоном и дополнительно проверяет,
  есть ли строки образца REPs на листе «СВОД_операций» тестовой книги (по правилам в скрипте).

Примеры (пути к образцу подставьте свои; одна строка — удобно для bash и cmd):

  python scripts/compare_svod_sheet.py --sample "путь/к/эталону_СВОД.xlsx" --test 2026_01/2026_01_Ord_Quantity.xlsx --overwrite-output-sheet

  python scripts/compare_reps_sheet.py --sample "путь/к/эталону_REPs.xlsx" --test 2026_01/2026_01_Ord_Quantity.xlsx --overwrite-output-sheet

Результат: в тестовую книгу добавляется лист отчёта (по умолчанию «СВОД_сверка» или «REPs_сверка»);
расхождения подсвечиваются, в консоли — краткая сводка (только образец / только тест / несовпадения).
Повторный запуск: флаг --overwrite-output-sheet, иначе переименуйте --output-sheet.

Подробности и типичные оговорки: memory/Svod_sheet_spec.md (блок про compare_svod_sheet.py),
memory/REPs_sheet_spec.md (блок про compare_reps_sheet.py). Отдельного скрипта сверки листа
«Количество поручений» в проекте нет — при корректном СВОД проверяйте матрицу выборочно или
сравнивайте с эталонной книгой вручную в Excel.
